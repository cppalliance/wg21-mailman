{% load i18n gravatar static %} {% comment %} Shared WG21 primary navbar (navy gradient, gold rule, emblem + wordmark + breadcrumb + optional search + avatar). Used by both Postorius and HyperKitty base templates so chrome stays identical. The avatar (Gravatar) is the sole account entry point on both auth states: - Authenticated: dropdown -> wg21/account_menu.html - Anonymous: dropdown -> wg21/auth_links.html (Sign In / Sign Up) django-gravatar2's default fallback ("mm" / mystery-man) covers the empty email case for anonymous users. Params: brand_url - URL name for the brand/home link (e.g. 'hk_root', 'list_index'). Also used as the logout ?next= target. breadcrumb_label - Already-translated string shown after the ">" chevron. search_action - Optional URL name for the search form action. If omitted, the search field (and the collapse toggler) are not rendered. search_query - Optional current search query string. breadcrumb_current - Optional extra crumb after breadcrumb_label (overview passes the list display name). When omitted, breadcrumb_label is the current page. breadcrumb_parent - Optional middle crumb, shown between breadcrumb_label and breadcrumb_current (All Threads passes the list display name here). Ignored unless breadcrumb_current is also set. breadcrumb_parent_url - Optional already-resolved URL for breadcrumb_parent. Without it the middle crumb renders as plain text. mlist - Optional MailingList; when set with search_action, search is scoped to that list and the placeholder / hidden input reflect it. Does not affect breadcrumbs. {% endcomment %} {% url brand_url as logout_next_url %} {% trans 'Logout' as logout_label %}
